# トリミング比率固定モードの設計

## 背景と目的

現在の画像トリミングは選択範囲を自由比率で指定し、適用先の表示枠と比率が異なる場合は黒または白の余白を付けている。これに加えて、利用者がプレビュー枠いっぱいに画像を表示したい場合に、表示枠と同じ比率へ固定して余白を出さない選択肢を提供する。

## 対象範囲

既存の `ImageCropField` を利用する全画像入力を対象とする。

- Music Player、Apple Music、YouTube Music、Spotify の正方形カバー
- Instagram Reel の9:16背景
- Instagram Reel の正方形アイコン

回転、反転、フィルターなど既存の対象外機能は追加しない。

## 操作仕様

ダイアログ内に「枠いっぱいにする」トグルボタンを追加する。

- 初期状態はOFF。従来どおり自由比率で選択し、必要に応じて余白を付ける。
- ONにすると `targetAspect` と同じ比率で選択枠を固定する。
- ON中も選択範囲の内部ドラッグによる移動と、四隅・辺のドラッグによる拡大縮小を許可する。ただし比率は維持する。
- ONへ切り替えると、現在の選択範囲の中心をできるだけ維持しながら、画像内に収まる最大の対象比率へ調整する。選択範囲が未確定の場合は中央の対象比率を使用する。
- OFFへ戻すと自由比率へ戻し、現在の選択位置と大きさを維持する。
- プレビューはON時に `cover`、OFF時に `contain` で表示する。
- 「完了」時はONなら `fit: 'cover'`、OFFなら `fit: 'contain'` を保存する。
- 余白色の選択状態はON/OFFを切り替えても保持する。ON時は余白が表示されないが、OFFへ戻すと再び使える。

ボタンには `aria-pressed` を設定し、ON時は「プレビュー枠と同じ比率で固定中」と分かる日本語の補助文を表示する。

## データモデル

`EditableImage` に次の任意プロパティを追加する。

```ts
cropAspectLocked?: boolean;
```

未指定は `false` として扱い、既存の状態と互換にする。再編集時は保存値を初期トグル状態へ復元する。`fit` は既存どおり、未調整のデフォルト画像と自由比率の未完了状態では `cover`、自由比率の完了状態では `contain`、固定比率の完了状態では `cover` とする。

## 実装方針

- `ReactCrop` の `aspect` に `cropAspectLocked ? targetAspect : undefined` を渡す。
- 現在のパーセント選択範囲を対象比率へ変換する共通ユーティリティを追加する。変換は選択範囲の中心を基準に行い、画像境界からはみ出さないようにクランプする。
- トグル切り替え後のプレビュー生成は、調整後の選択範囲と同じ状態で行う。
- 既存のPNG生成、余白色、キャンセル、Esc、中央に戻す、保存キャプチャの仕組みは変更しない。
- 固定モードでも画像自体を拡大して出力せず、既存のCanvas上限を維持する。

## テストと受け入れ条件

- 初期状態が自由比率・OFFである。
- トグルONで `aria-pressed="true"` になり、固定モードの補助文が表示される。
- トグルON時に現在の選択範囲が対象比率へ変換され、中心と画像境界が保たれる。
- ONで完了すると `fit: 'cover'` と `cropAspectLocked: true` が返る。
- OFFで完了すると従来どおり `fit: 'contain'` と `cropAspectLocked: false` が返る。
- 再編集時に保存済みの固定状態を復元する。
- 既存の自由比率、余白色、キャンセル、Esc、画像生成、各アプリ統合テストが通る。
- ブラウザで正方形・9:16の両方について、ON時に余白がなく、OFF時に余白色が反映される。
